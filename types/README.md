# Common type families

A common type family is a set of shared `common.*` types, such as `common.ticket` and its kinds, together with guidance on how to use them. It belongs to no app, service or person. Each family is a plugin: an owner adds it to their Marfa when they want its types.

Each family gets its own folder here. The first family, Tickets, is on its way, and installing a family arrives with it.

Connectors, the other kind of plugin in this repository, live in [`connectors/`](../connectors).
