# Common type families

A common type family is a set of shared `common.*` types, such as `common.ticket` and its kinds, together with guidance on how to use them. An owner installs a family into their Marfa as a plugin. A family belongs to no app, service or person: any app, connector or person can read and write its types.

Each family gets its own folder here. The first family, Tickets, is on its way.

Connectors, the other kind of plugin in this repository, live in [`connectors/`](../connectors).
